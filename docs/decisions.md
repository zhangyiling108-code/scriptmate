# ScriptMate 决策记录

## 2026-10-13：可分享的独立 MCP 入口

- 面向其他使用者提供本地 stdio MCP 服务，复用 Python 素材引擎；CLI 与现有产物结构保留。
- 不要求特定 Agent、Skill 或提示词。模型和素材源依然需要使用者自己的配置、密钥与额度。
- 长匹配立即返回 UUID 任务 ID，每进程一次执行一个匹配；状态读取不重跑任务，默认关闭下载及所有降级，完成结果可重启读取，未完成任务不自动恢复付费调用。
- MCP 依赖可选安装，固定在已验证的官方 SDK 1.30.0；轮子包含共享数据文件，并验证离开源码目录后的运行。远程托管、共享账户和公开发布不纳入本次范围。

## 2026-10-04：文本预筛与画面评分分离

- JEV 只按元数据排列有限候选，不决定最终画面分；DeepSeek `deepseek-flash` 用实际图片完成最终评分。
- 保留旧配置结构，新增可选 `prefilter_model` 与证据字段。元数据评分不能标为视觉核验；只看视频封面不能推断片段动作。
- 当前本机要求主选具备实际图片核验。没有图片、视频封面或显式启用的评分降级结果保留人工复核。

## 2026-06-24：ScriptMate 保持素材匹配定位

- ScriptMate 主目标是文案到素材方案包，不把完整自动剪辑作为默认目标。
- 口播成片或动画渲染需求应先判断是否交给 Remotion 子项目处理。

## 2026-06-24：CLI 稳定优先

- 新功能优先作为可选参数或新命令加入。
- 不随意破坏 README 中已有命令和输出文件名。
