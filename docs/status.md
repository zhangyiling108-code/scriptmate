# ScriptMate 当前状态

更新时间：2026-10-13

## 独立 MCP 接入（0.2.0）

- 0.2.1 增加 `setup-mcp` 配置向导和 `check-mcp` 无 API 消耗的协议连接检查；发布入口与教程见仓库首页。

- 增加本地 stdio MCP 入口 `scriptmate-mcp`，通过可选 `[mcp]` 依赖安装；MCP 需要 Python 3.10+，CLI 仍支持 Python 3.9。
- 复用现有分析、搜索和匹配引擎，提供任务状态/分段进度、取消、结果分页和完成结果的重启读取。默认不下载、不降级。
- 分享说明见 `docs/mcp.md`，凭据、缓存、历史输出和本地素材库不进入分享包。
- 仅本地接入；通过 GitHub 发布，未部署远程 MCP、发布 PyPI 或注册公开目录。本次模型验证使用模拟数据，真实账户与不同客户端的图形界面接入需要分别验证。

## 视觉评分改造

- JEV 可配置为文本预筛，DeepSeek `deepseek-flash` 对候选图片核验；预筛分不会覆盖最终画面分。
- 输出区分元数据、实际图片与视频封面，保留可见内容及两阶段模型记录。
- 本机开启实际图片主选门槛；视频仍需人工核对完整片段，未实现多帧动作分析。
- 单个预览图片不可读取时记录原因并保留人工复核，不中断其他候选核验，也不缓存该次失败。

## 当前定位

- 面向口播/科普/行业分析视频的素材匹配工具。
- 重点输出 `analysis.json`、`manifest.json`、`summary.md`、`segments_overview.csv` 和每段素材候选。

## 下次优先动作

- 维护 CLI 时先确认 README 中的快速开始命令仍能成立。
- 对视频成片需求，先判断应使用 ScriptMate 素材匹配，还是 `opc-voiceover-remotion` 渲染流程。

## 风险提醒

- `output_*` 目录多为历史产物，修改前先确认是否为当前任务范围。
- 默认不自动下载大量素材，优先给候选链接和可人工筛选结果。
